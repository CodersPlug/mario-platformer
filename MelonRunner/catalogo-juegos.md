# Catálogo de juegos — Programa Polgár

Fichas listas para ~6 años. Duración típica de misión: **8–15 min**.  
Materiales casi siempre caseros. Volver al programa: [`programa-polgar.md`](programa-polgar.md).

Leyenda de modalidades: **D** digital · **F** físico · **H** híbrido.

---

## Digitales

### D1 — Azulín

Una ficha digital más del catálogo (no es el laboratorio principal del programa).

| | |
|--|--|
| **Modalidad** | Digital |
| **Pilares** | Lógica, mate, música, idiomas, alimentación (según misión) |
| **Materiales** | iPad · [Azulín](https://codersplug.github.io/mario-platformer/) |
| **Reglas** | Arrastrar / tirar / colocar props del dock. Reiniciar con el ícono. Una misión = una consigna. Intercambiable por D2/D3 u otra app. |
| **Éxito** | Cumplir la consigna del día (ej. exactamente 3 objetos; 2 rebotes; nombrar en L2 al colocar). |
| **Más fácil** | Solo juego libre 8 min + 1 objeto. |
| **Más dura** | 2 reglas encadenadas (“primero cono, después pelota”). |
| **Sin iPad** | Usar F2 (conteo/patrones) o F6 (hipótesis) con la misma consigna. |

Misiones rápidas: exactamente N piezas · pelota toca pared y vuelve · “plato” de 3 colores · 3 tiros al ritmo · solo colocar si dice la palabra L2.

---

### D2 — Ritmo / eco en iPad

| | |
|--|--|
| **Modalidad** | Digital |
| **Pilares** | Música, lógica |
| **Materiales** | Voz + palmadas; opcional iPad con SFX de cualquier app (Azulín u otra) |
| **Reglas** | Coach marca un patrón (palmada-palmada-pausa). Ella lo ecoa. Si hay app abierta, cada acción sigue el patrón. |
| **Éxito** | Repetir 3 patrones seguidos sin ayuda. |
| **Más fácil** | Solo 1 patrón de 2 golpes. |
| **Más dura** | Ella inventa el patrón y el coach lo ecoa. |

---

### D4 — Cuando sea vieja

| | |
|--|--|
| **Modalidad** | Digital (iPad) |
| **Pilares** | Creatividad, oficio (imaginar el yo futuro), idiomas (narrar) |
| **Materiales** | iPad · [Cuando sea vieja](https://codersplug.github.io/mario-platformer/futura/) · cámara frontal |
| **Reglas** | 1) Selfie con la cámara de adelante. 2) La app estima la edad y pone el slider ahí. 3) Deslizar hacia adelante (más grande/vieja) o atrás (más chica). La foto no se sube. |
| **Éxito** | Ella mueve el slider y cuenta 1 frase: “Cuando sea vieja voy a…” |
| **Más fácil** | Solo mirar 3 edades (ahora / grande / viejita). |
| **Más dura** | Inventar una misión del programa para su “yo viejita”. |

---

### D3 — Scratch Jr / bloques (nivel D)

| | |
|--|--|
| **Modalidad** | Digital |
| **Pilares** | Lógica, oficio |
| **Materiales** | Scratch Jr (u otra app de bloques) |
| **Reglas** | Armar una secuencia WHEN → DO de 2–3 bloques. Probar. Contar qué pasó. |
| **Éxito** | El personaje hace lo que ella dijo antes de tocar play. |
| **Más fácil** | Un solo bloque “mover”. |
| **Más dura** | Repetir + sonido + mensaje. |

Usar recién cuando el oficio esté en nivel D (ciclo avanzado).

## Físicos

### F1 — Cartas “Si… entonces…”

| | |
|--|--|
| **Modalidad** | Físico |
| **Pilares** | Lógica, oficio |
| **Materiales** | 6–10 papeles: mitad “SI …” (clap, salto, tocar azul) / mitad “ENTONCES …” (reír, girar, decir *blue*) |
| **Reglas** | Robar 1 SI + 1 ENTONCES. Actuar la regla 3 veces. Ella puede inventar 1 carta nueva al final. |
| **Éxito** | Cumplir 3 reglas distintas. |
| **Más fácil** | Coach elige las cartas. |
| **Más dura** | Encadenar 2 reglas (SI A → ENTONCES B; SI B → ENTONCES C). |

---

### F2 — Carrera de patrones

| | |
|--|--|
| **Modalidad** | Físico |
| **Pilares** | Matemáticas |
| **Materiales** | Tapas, bloques o calcetines de 2–3 colores/formas |
| **Reglas** | Coach arma un patrón de 4 (ej. rojo-azul-rojo-azul). Ella lo copia. Luego continúa 2 piezas más. |
| **Éxito** | 3 patrones copiados bien. |
| **Más fácil** | Solo 2 colores, patrón ABAB. |
| **Más dura** | Patrón ABC / contar “¿cuántos rojos?”. |

---

### F3 — Cocina arcoíris

| | |
|--|--|
| **Modalidad** | Físico |
| **Pilares** | Alimentación |
| **Materiales** | Plato real + 3 alimentos/colores naturales (fruta, verdura, agua) |
| **Reglas** | Armar un “plato feliz” con al menos 3 colores. Nombrar cada color. Probar 1 bocado juntos. |
| **Éxito** | Plato con 3 colores + 1 bocado sin pelea. |
| **Más fácil** | 2 colores. |
| **Más dura** | Ella elige el menú del snack del día siguiente. |

---

### F4 — Eco de palabras

| | |
|--|--|
| **Modalidad** | Físico |
| **Pilares** | Idiomas |
| **Materiales** | Pelota blanda (o peluche) · 3–5 palabras L2 del mes |
| **Reglas** | Al pasar la pelota, decir 1 palabra L2 (o repetir la del coach). 8 pases = ronda. |
| **Éxito** | Completar 1 ronda con las 3 palabras del día. |
| **Más fácil** | Solo eco (ella repite). |
| **Más dura** | Ella elige la palabra; coach traduce / usa en frase corta. |

---

### F5 — Orquesta de sillas

| | |
|--|--|
| **Modalidad** | Físico |
| **Pilares** | Música |
| **Materiales** | 3–4 “instrumentos” caseros (olla+cuchara, arroz en pote, palmadas, voz) |
| **Reglas** | Coach dirige: grave = lento, agudo = rápido (o solo palmada = tocar). Ella toca / dirige 1 turno. |
| **Éxito** | Seguir el tempo 1 minuto + dirigir 30 s. |
| **Más fácil** | Un solo instrumento. |
| **Más dura** | Inventar jingle de 4 notas y repetirlo. |

---

### F6 — Patio hipótesis

| | |
|--|--|
| **Modalidad** | Físico |
| **Pilares** | Lógica |
| **Materiales** | Pelota + cono/caja/almohadón · espacio seguro |
| **Reglas** | Ella dice “¿qué pasa si…?” (ej. tiro suave vs fuerte). Probar. Contar el resultado en 1 frase. |
| **Éxito** | 2 hipótesis probadas + 2 frases de resultado. |
| **Más fácil** | Coach propone la hipótesis. |
| **Más dura** | Planificar 3 pasos antes de tirar. |

## Híbridos

### H1 — Misión desbloqueo

| | |
|--|--|
| **Modalidad** | Híbrido |
| **Pilares** | Alimentación, hábitos |
| **Materiales** | Snack/comida con color · sticker · (opcional) cualquier ficha digital |
| **Reglas** | 1) Completar el snack/hábito manzana. 2) Pegar sticker. 3) Opcional: 3–8 min de **una** ficha D con 1 misión corta. |
| **Éxito** | Snack + sticker (+ misión digital si hubo pantalla). |
| **Más fácil** | Solo snack + sticker. |
| **Más dura** | Ella elige qué juego digital desbloquear. |
| **Sin iPad** | Quedarse en F3 + sticker (cuenta como físico). |

---

### H2 — Foto-regla

| | |
|--|--|
| **Modalidad** | Híbrido |
| **Pilares** | Lógica, oficio |
| **Materiales** | Piezas físicas (bloques/almohadones) · foto (opcional) · papel o cualquier app |
| **Reglas** | 1) Armar algo real. 2) Decir la regla (“si toco la torre, se cae”). 3) Dibujar, narrar o recrear en digital. |
| **Éxito** | Construcción + regla dicha en voz alta + registro (foto, dibujo o escena). |
| **Más fácil** | Solo construcción + 1 frase. |
| **Más dura** | Dos reglas y enseñárselas al coach. |
| **Sin iPad** | Dibujar la regla en papel. |

---

### H3 — Diccionario vivo

| | |
|--|--|
| **Modalidad** | Híbrido |
| **Pilares** | Idiomas |
| **Materiales** | 3 objetos reales · (opcional) app para “colocar” equivalentes |
| **Reglas** | Tocar el objeto real, decir nombre L2; si hay app, colocar el equivalente (si no, dibujar o señalar). |
| **Éxito** | 3 objetos nombrados y “colocados” / señalados. |
| **Más fácil** | 2 objetos; coach dice primero. |
| **Más dura** | Frase corta en L2 (“red ball”). |
| **Sin iPad** | Solo objetos reales + dibujo (F4 ampliado). |

---

### H4 — Partitura de tiros

| | |
|--|--|
| **Modalidad** | Híbrido |
| **Pilares** | Música |
| **Materiales** | Palmadas/voz · (opcional) juego digital del día |
| **Reglas** | Coach (o ella) hace 1-2-3 palmadas; en cada palmada ella hace una acción en el juego digital (o tira un peluche si no hay app). |
| **Éxito** | 3 tiros alineados al ritmo sin adelantarse. |
| **Más fácil** | Ritmo muy lento; 2 tiros. |
| **Más dura** | Ella crea la partitura (silencio + golpe). |
| **Sin iPad** | Tirar peluches reales al ritmo (F5 + F6). |

---

## Cómo elegir rápido

| Si hoy querés… | Empezá por |
|----------------|------------|
| Cero pantalla | F1–F6 |
| Solo iPad | Cualquier D (rotar; no default a D1) |
| Unir snack / casa + juego | H1 o H3 |
| Que ella cree | Sábado: cualquier ficha en modo “inventá vos la regla” |
